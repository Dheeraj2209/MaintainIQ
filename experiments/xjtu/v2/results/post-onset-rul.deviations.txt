DV1 pre-onset semantics: pipeline_states(pre_onset="provisional") (harness2 default): stage-2 conditions while O=0 are evaluated at a provisional onset = current row (tso=0); published q50 stays null while healthy. Chosen because PROTOCOL 2.2 counters run concurrently and the 1.3 latency floors assume it.
DV2 warm-up: N/D/D'/variants go through causal.replay, which gates rows < 20 (healthy). R0/R1 keep the frozen ungated causal.states_r mapping as primary (as harness2 / section 4.5).
DV3 stage-2 training and conformal-calibration rows: rows at/after the stage-1 HARD-LATCH first onset (FPT) of each training bearing, for both hysteresis options (hysteresis only changes the replay). Bearings with no onset contribute no rows.
DV4 feature details the protocol leaves open: OLS slopes of log r5 over trailing 10/30 rows (fewer rows early, 0 with <2 rows); kurtosis z = robust z vs commissioning median/MAD, floor max(1.4826*MAD, 0.02*|med|), max over h/v, trailing 5-row median; envelope ratio = max_c env_rms_c / med20_c, unsmoothed, log; r5-based features use the stage-1 reference mode (self/fallback); peak and kurtosis/envelope use the commissioning median.
DV5 TSO: L = median over training bearings with an onset of true RUL at their causal FPT (same as harness2.p1_baselines). At provisional pre-onset rows TSO q50 = L.
DV6 HGB-q: early_stopping=False set explicitly (identical to sklearn 'auto' at < 10000 rows). Seeds: random_state = 42 + outer fold for every inner and refit model of that outer fold; the all-15 modal run uses 42 + 15.
DV7 published output: interval [q10, q90] at alpha 0.1 with the chosen binning, whatever model_crit alpha is selected; failure_within_horizon_probability from q05/q10/q50/q90/q95 (alpha 0.05 and 0.1 bounds) via harness2.prob_within; p0 for O=0 rows (and warm-up rows).
DV8 p0 = bearing-equal mean, over the 14 training bearings with any O=0 row >= 20, of the fraction of those rows with RUL <= 120, using the selected candidate's inner replay states.
DV9 stage-1 selection scores stage-1 configs under the hard latch (stage-1 only states). If no stage-1 config is eligible, D's stage 1 is used (logged).
DV10 EXPLORATORY variants requested by the task, outside the pre-registered decision: (a) ORACLE: onset latched at the GT primary point t_on (gt_on_row; trigger = row >= gt_on_row, k = 1), stage 2 trained on rows after each training bearing's gt_on_row.
